# 答えの表を回して、ずれに強い計算を作る

> Advanced Cryptography Program 2026 に対応する非公式・独立教材です。
> 提携・公認ではありません。お問い合わせは TenkaCloud へ。

Week 5 / 順序563 / 難易度3 / 200点 / draft / 目安40〜60分。

暗号の計算に使う表を点検する担当者として、小さな数の計算を追います。
丸める順序で答えが変わる例を作り、読む位置のずれに耐える表へ直します。

## 参加者の進め方

1. 「起動」→「証拠を確認」。`rotation_drill.py` の最初の `return None` を
   `return (p,q,n,q//p)` に替えて実行し、`params ->` の値を最初の欄へ提出します。
2. 次の五関数も、無料の対応コードを使って埋めます。公開テストは小さな見本と照合し、
   自分の数で計算した値を表示します。未記入の別の欄があっても提出できます。
3. `window` では丸め方の反例、`edge` では新しい表を構成します。
   指定された全条件を満たす構成なら、模範解答と違っても受理します。

| 回答欄 | 確かめること | 点数 |
| --- | --- | ---: |
| params | 元の数1段の間隔 | 20 |
| phase | 鍵が選ぶ分を引く | 15 |
| testpoly | 答えの表全体 | 15 |
| rescale | 三つの値を表の目盛りへ丸める | 20 |
| index | 別々に丸めてから引く | 15 |
| readout | 一周で符号が反転する表を読む | 15 |
| window | 丸める順序で答えが変わる例 | 50 |
| edge | 全メッセージ・全ずれで正しい表 | 50 |

必要な規則と小さな見本は無料です。任意ヒントは各欄「仕組み → 見本 → 自分の画面での手順」
の3段、各2点、計48点。誤答は10点減点です。後半の完成コードは掲載しません。
実際の表は8個、公開見本は4個なので、見本の答えを丸ごと転用せず規則を当てはめます。

## 模型と境界

観察者には鍵を見せます。回転位置と符号つき表引きの算術模型であり、暗号化された回転や
暗号文のノイズ更新は行いません。出力は普通の数です。Pythonの `round` は最も近い整数を
選び、ちょうど中間なら偶数にします。四捨五入とは異なります。指定した下半分の元の数でのみ
成立を保証します。「上半分なら必ず誤答」とはしません。0は符号を反転しても0だからです。

形は `(p,n,q)=(4,8,32)` または `(8,8,32)`。隠すために使う列の数は一桁です。
公開の補助関数で規則を説明し、独立した非公開判定で前半六つの値と後半二つの構成を確認します。
反例は位置の差だけでなく答えの差を要求し、どちらの丸め順序も常に正しいとは仮定しません。

参加者イメージはスターター、公開テスト、補助関数、Portal APIだけを含みます。
生成用の秘密、生成器、非公開テスト、模範解答は採点用または作者用イメージに置きます。
参加者コードには取得済みの公開情報だけを渡します。提出を開始回へ結び付ける識別値は認証では
ありません。非公開ポートの採点用コンテナは参加者コードを実行せず、値と構成を判定します。
直接回答の不正解理由は返しません。

Linux seccompで参加者コードの通信、親のメモリ・停止要求・リソース制限へのアクセスを制限し、
子プロセスにも引き継ぎます。実行後に残る子は終了します。CLIも同じ制限を使い、設定できなければ
実行しません。両コンテナは非root、読み取り専用でリソースを制限し、18138番は127.0.0.1にだけ
公開します。Dockerを操作できる人は自分のイメージを調べられます。
