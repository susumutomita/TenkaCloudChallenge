# 消えた案内を取り戻そう — S3の過去版

[English](README.md) · [企画 #887](https://github.com/susumutomita/TenkaCloudChallenge/issues/887)

会議室の案内が間違った内容に上書きされました。残っている過去の版を調べ、正しい案内を取り戻そう。

これは開催者が選ぶ追加Challengeです。初回の準備GateとBattleの2問セットへ自動追加しません。4人で操作・資料を読む・説明・確認の担当を交代します。

## 遊び方と採点

ポータルの「AWS Consoleを開く」でチームの権限へ接続し、GameUrlを開きます。対象のバケットとファイル名、操作手順、成功条件、無料の3段階ヒントが表示されます。実AWSの操作確認と説明問題を両方完了すると合言葉を1つ発行。ポータルへ提出すると100点、誤った合言葉は5点減点です。画面内の確認・ヒントは無料。引き継ぎコードは採点用の合言葉とは別で、チーム内だけで共有します。

過去の履歴を残したまま、新しい現在の版が正しい案内になる。 検査はバケットの4つの公開防止設定と現在の実オブジェクトを読みます。復元問題ではバージョニングと過去版の保持も確認します。過去版を開いただけでは現在の内容は変わりません。個々のダウンロード操作を監査した証明ではないため、仲間の端末で内容を読む確認は役割として実施します。

## 構成・権限・費用

チームごとのAWSアカウントへ、非公開S3バケット1個、ミッション用Lambda、初期データと撤収用Lambda、保存期間1日のログ、IAMロールを作成します。S3はバージョニングとSSE-S3（AES256）を有効にし、顧客管理KMSキーは作りません。参加者は指定バケットの一覧と handover.txt の読み書きだけを許可。公開設定・ポリシー・過去版削除・採点関数の取得は許可しません。信頼ポリシーのExternalIdは必須です。

データ容量、S3リクエスト、Lambda、ログ、転送には料金が発生し得ます。東京 ap-northeast-1、約10分を初回の目安とし、現在の料金とイベント全体の費用を開催者が確認してください。無料とは保証しません。ファイルを繰り返し上書きすると保存される版が増えます。

管理画面からデプロイを削除します。後片付け処理は全バージョンと削除マーカーを消してからバケットを削除します。一部削除エラーはFAILEDになり、ログを確認して再試行します。バケット・関数・ログ・ロールが残っていないことを確認し、共有端末の進捗を消してください。

## 検証

共通実装は [aws-intro](../../runtimes/aws-intro/README.md)。このディレクトリで `make build && make test`、カタログルートで `make install && make agent-gate`。共通テストでは実オブジェクトの比較、間違った現在版の拒否、公開防止、履歴、削除エラー、生成Lambdaとの一致をSDKのテストデータで確認します。

`make preview` はlocalhost限定の画面プレビューです。実AWSの操作と採点を行わないことを画面に表示し、明示したテストデータなしでは操作確認は成功しません。実AWSのコンソール権限・保存・復元・撤収と公式得点は開催前の任意リハーサルで確認してください。
