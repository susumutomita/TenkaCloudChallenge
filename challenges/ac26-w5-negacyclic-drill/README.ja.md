# 符号の裏返りで計算し、ずれに強くする

> Advanced Cryptography Program 2026 に対応する非公式・独立教材です。

Week 5 / 順序565 / 難易度3 / 200点 / draft / 目安40〜60分。

二つの入力が両方1のときだけ0を返す、小さなNAND装置を点検します。
符号つき表引きを追い、ずれで壊れる入力と、指定された全入力・全ずれで成立する修理を構成します。

## 参加者の進め方

1. 「起動」→「証拠を確認」。`negacyclic_drill.py` の最初の `return None` を
   `return (p,2*n,n,(2*n)//p)` に替えて実行し、`params ->` の値を最初の欄へ提出します。
2. 次の五関数も、無料の対応コードを使って埋めます。公開テストは小さな見本と照合し、
   自分の数で計算した値を表示します。未記入の別の欄があっても提出できます。
3. `constants` へ `[入力a,入力b,合計ノイズ]` を返し、元の上限を越えた失敗を示します。
   `margin` へ `[bias,weight_a,weight_b]` を返し、入力四通りと合計ノイズ0〜`repair_noise`の
   すべてでNANDを保つ計算を作ります。全条件を満たす別解も受理します。

| 回答欄 | 確かめること | 点数 |

## 模型と境界

暗号化したTFHEや暗号文の更新ではなく、見える数の算術模型です。
全て1の表を読み、n位置進むと符号が反転します。ビット0/1をp−1/1に置き、
元の位相 `(1-m1-m2)%p` をD倍して合計ノイズを引き、周期で割った余りを取ります。
元のノイズ上限内なら入力(1,1)だけが負。符号1をビット1、−1をビット0と読むとNANDです。

p=16,n=8,q=16,D=1です。二つの入力から来るずれの合計を1以下にし、
調べる位置を変えます。負の位置や周期を越えた位置も扱います。修理後は合計ノイズ2か3まで
耐える必要があります。古い説明のn−3Dという距離と異なり、元の仕掛けは合計ノイズ2で
混合入力の位置が0より下へ回り込み、先に壊れます。修理は三つの係数を変え、全入力・全ずれを
確認します。最後は重みを掛けた計算の後のずれを与える模型であり、実際の入力暗号文で重みが
ノイズを増やす過程を再現するとはしません。

参加者イメージはスターター、公開テスト、補助関数、Portal APIだけを含みます。
生成用の秘密、生成器、非公開テスト、模範解答は採点用または作者用イメージに置きます。
参加者コードには取得済みの公開情報だけを渡します。提出を開始回へ結び付ける識別値は認証では
ありません。非公開ポートの採点用コンテナは参加者コードを実行せず、値と構成を判定します。
直接回答の不正解理由は返しません。

公開します。Dockerを操作できる人は自分のイメージを調べられます。

## ローカル確認と終了

この問題のディレクトリで実行します。

```bash
make inspect
make test                  # 未記入なら失敗するのが正常

make verifier-down
```

クラウドのリソースは作らず、停止までローカルのCPU・メモリを使用します。AWSの利用リージョンや
セッション費用は、この実行方式にはありません。
