## 参加者の進め方

1. 「起動」→「証拠を確認」。自分のq0をpolyの最初の値にし、与えられた式でQ(1),Q(2)も求めます。
2. 回答欄へa,b,cと提出し、正誤表示を確認。名前を揃えた8回答欄を順に進みます。
3. 任意のPython経路では、最初のreturn Noneを `return (q(qs,0,p), q(qs,1,p), q(qs,2,p))` に変更して
   公開テストを実行します。小さな見本と照合した後、自分のコードが計算した今回の値が表示されます。
   他の欄が未記入でも回答でき、公開テストのPASS自体は提出ではありません。

必要な式と小例は本文に掲載。各欄のヒントは「仕組み → 小例 → 自分の画面の名前で手順」の3段です。
各2点、計48点で、従来の1段×8欄と減点合計は同じです。誤答は10点減点です。

| 回答欄 | 入れる値 | 点数 |
|---|---|---:|
| poly | Q(0),Q(1),Q(2) | 20 |
| fold | Q1(0),Q1(1),Q1(2) | 25 |
| fold2 | c+beta2*dの余り1個 | 25 |
| query | Q(x),Q(−x) | 20 |
| recover | 復元した偶数・奇数の値、直接計算した偶数・奇数の値 | 25 |
| consistency | 元の二点から混ぜた値、Q1(x²) | 25 |
| cheat-caught | 元の二点から混ぜた値、すり替えたQ1(x²) | 30 |
| miss-points | 後出しの一次式・全検査を通る高次式の差、計6係数 | 30 |

最後は自分で二つの偽物を構成します。検査位置を先に知る場合と次数上限を外す場合で、
異なる弱点を利用します。全条件を満たす6係数なら正解で、特定の解との比較ではありません。

## 数学の範囲と二つの入力資料

講義の偶奇分解・折り畳みを、学習ノートの二式の和と差による復元の導出につなぎました。
係数が全て見える、一段の照合の算数模型です。完全なFRI証明、低次数の並びへの近さの検査、
秘密の保護を実証したものではありません。二回目の定数は計算しますが、その開示を一回目の照合で
検査したとはしません。次数の上限は切り下げで3→1→0、すり替えで実際の次数が下がる場合もあります。

最初の折り畳みが定数にならず、差d0+d1Yが非ゼロの二乗位置で消え、表示したxでは検出するように
出題値を選別しています。無作為なプロトコル実行ではありません。固定した差を非ゼロ位置から
一様に検査する一回の見逃し率は2/(p−1)。独立・復元抽出なら積になりますが、重複禁止や±の
意図的な選択にその積は使えません。FRI全体の安全性の上限とは区別します。

## 実行の境界

参加者イメージはスターター、公開テスト、提供済み算術、Portal APIだけを持ちます。秘密の生成値・生成器・
非公開テスト・期待回答は採点用と作者用イメージだけです。参加者コード実行前に公開値を取得します。
提出を開始回に結び付ける識別値は認証ではありません。採点コンテナは値だけを判定し、参加者コードを実行せず、
直接回答の不正解理由も返しません。

Linux seccompで通信、親のメモリ・停止要求・制限の変更、プロセスグループからの離脱を制限し、子にも継承します。
実行後に残る子は終了します。CLIも同じ制限で、設定できなければ実行しません。両サービスは非root・
読み取り専用・リソース制限あり。18135番だけを127.0.0.1に公開します。Docker管理者への完全な秘匿ではありません。
