# つながるオフィスの準備 — 4人で学ぶGate

[English](README.md) · [本戦](../office-link-gameday/README.ja.md) · [60分の運営台本](../office-link-gameday/OPERATOR.ja.md)

GameDayに必要な「同じ地域を見る・必要な権限だけ渡す・正常な控えへ戻す・結果を確認する」を、例と相談問題で学ぶChallengeです。4人で説明・例を読む・操作・確認を担当し、1問ごとに交代します。最初の一手はポータルの **GameUrl**。表示された1問だけを相談して答えます。

## 修了してから本戦へ

4段階の成功をサーバーで順に確認し、**最後にだけ修了の合言葉を1つ**返します。これを既存ポータルへ提出すると100点。途中の正解では公式加点しません。既存Progression Gateの「最初の加点で解放」という条件でも、学習途中で本戦が開きません。

開催者はイベントに本問題と `office-link-gameday` だけを入れ、[Gate設定](../office-link-gameday/event-gate.json)を適用します。Gateは既定OFFです。管理画面の「進行 / Gate」でTenantAdminが有効にし、デフォルトを `required`、チーム上書きを継承、追加ボーナスを0にします。本戦は準備修了後に1つだけ解放。終えた内容の復習は可能です。設定しただけで個人全員の理解を証明するものではないので、司会は4人の説明を聞きます。

問題画面での試行・ヒントは無料。ポータルへ誤った合言葉を提出すると5点減点です。途中の引き継ぎコードは進捗用で、得点用ではありません。別端末で同じGameUrlを開いて引き継ぎコードを入力すると、検証された続きから再開できます。他チームのコードや改ざんは拒否します。

## 配信と安全性

AWS / CloudFormation + 既存 `flag` 採点を使います。チーム別Lambda Function URL、128MB Lambda、1日保持のCloudWatch Logs、IAMロールを作ります。`build.py` が同じ `app.py` と画面を `template.yaml` に埋め込みます。進捗コードは別の秘密鍵によるHMACで署名されます。ブラウザの段階番号を書き換えても次の段階や合言葉は取れません。

既存 `__RANDOM_PASSWORD__` がアクセス・進捗署名・採点用の3個の独立した乱数を注入します。採点用Outputはmetadataで宣言し、既存ポータルが参加者応答から除外します。初期HTML/JSに秘密や合言葉はありません。GameUrlと引き継ぎコードは同じチームだけで共有してください。問題画面は公式スコアを直接変更しません。

実行ロールは自分のログへの書き込みのみ。参加者ロールは標準のサインイン・CloudShell用権限と必須ExternalIdを保ち、Lambdaコード・環境変数・スタックOutputを読めません。リクエストやコードをログへ出しません。

## 費用・撤収・確認

初回リハーサルは東京 `ap-northeast-1`、学習の目安は20分です。呼び出し・実行時間・転送・ログに費用が発生し得ます。本体と本戦の費用は別です。EC2、NAT、RDS、S3バケット、Secrets Manager、カスタマー管理KMSキーは作りません。URLの不正アクセスもLambda呼び出しにはなるため、無料保証はしません。

終了後は管理画面で両問題のデプロイを削除し、Lambda・URL・ログ・ロールの削除を確認します。共用端末の保存データも消します。実AWSの採点・ロック/解放・撤収と、初参加者の理解度は開催前リハーサルで確認します。

カタログルートで `make install` 後、このディレクトリで `make build && make test`。`make preview` で同じhandlerをlocalhost:5685で確認できます（Python 3.12以上・カタログ指定Bun）。プレビューはGateの学習画面と判定だけで、公式ポータルの採点・イベントGate・複数チーム順位は提供しません。停止はCtrl-C。最後にカタログルートで `make agent-gate` を実行します。
