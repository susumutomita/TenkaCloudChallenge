# NIGHTSHIFT — 夜間バッチを守れ

English: `cat /srv/nightshift/START-HERE.en.md`

あなたは通販会社の夜間運用チームです。注文をまとめて処理する「バッチ」に、不審な動作と情報漏えいの疑いが見つかりました。ターミナルから調べ、安全に直し、正常な注文処理を続けてください。

最初に `id`、`ls -la /srv/nightshift`、`cat /srv/nightshift/logs/batch.log` を実行してください。今の利用者、引き継いだファイル、最近の注文処理が見えます。

## 使えるもの

BashとLinuxの標準コマンドだけです。Python・Node.js・専用攻撃ツール・外部ネットワークは使いません。`nano`で編集できます。`exit`で運営側ターミナルに戻れます。

「権限」は、誰がファイルを読んだり変更したりできるかの設定です。`ls -l`で確認できます。「PATH」は、短いコマンド名を入力したときに実行ファイルを探すディレクトリの順番です。

## 前半：調査と実証 / auditor / 300点

1. **予定外の読者（100点）**：バックアップにある演習用の精算キーが、一般の調査ユーザーから読めるという通報です。読めた値だけを `/srv/nightshift/submissions/leak.txt` に保存してください。実在の認証情報は入っていません。
2. **いつもと違う実行者（100点）**：あなたの置いたファイルが夜間バッチから呼ばれている疑いがあります。`/srv/nightshift/app` の処理を調べてください。batchユーザーだけが読める `/srv/nightshift/service/proof-token` を、batch自身によって `/srv/nightshift/evidence/path.txt` へコピーできれば実証です。コピーだけを行い、その後の正規の注文処理も続けてください。
3. **戻ってしまう設定（100点）**：担当者は「設定を直したのに、バッチを再起動すると以前の状態に戻る」と報告しています。原因となる起動スクリプトの絶対パスを、1行で `/srv/nightshift/submissions/startup.txt` に保存してください。`app` の起動設定とログが手がかりです。

バッチは約5秒ごとに動きます。手動で動かすときは運営に `tick` を依頼してください。

証拠を作ったら `exit` し、運営側で `./gameday.sh submit team1` を実行します。チーム名は運営の指定に合わせてください。何度提出しても減点はありません。修復フェーズに進むと調査得点は確定し、後から追加できません。

## 後半：修復 / operator / 700点

運営が `repair` へ切り替えた後、新しいシェルはoperatorで開きます。rootではありませんが、アプリの設定とスクリプトを修復できます。

必要な状態は「auditorが精算キーを読めない」「auditorが置いたコマンドでbatchの処理を差し替えられない」「バッチサービスを再起動しても元に戻らない」です。どれも注文処理を止めて達成してはいけません。前2件が各150点、再発防止が100点です。

注文処理は次の3項目が各100点です。
- 正常な注文の個数・単価・合計・精算キーから計算するチェックサムが正しい。
- 同じ注文IDを再送しても、二重に処理しない。
- 個数0、負数、数値でない値、余分な列がある注文は受理せず、拒否記録を残す。

チェックサムは、同じデータか確認するための計算値です。計算方法は既存の正規スクリプトにあります。現実の決済署名の実装例ではありません。

通常の入力は `注文ID,個数,単価`。個数は1〜999、単価は0〜999999の整数です。先頭の0を含む値も10進数として扱います。例：`ORDER-1,003,000050` は個数3、単価50、合計150です。出力は `注文ID,個数,単価,合計,チェックサム` です。

採点は運営側の `./gameday.sh score team1`。採点中にバッチサービスを実際に再起動し、修復が失われないか検査します。OS再起動ではありません。採点中の編集は止めてください。採点は現在の状態を評価するため、再び壊れると修復・正常処理の得点は下がります。

## 境界

対象はこの使い捨て環境の `/srv/nightshift` と自分のホームだけです。運営ホスト、採点器、他チーム、コンテナ外は対象外です。ネットワーク攻撃、持ち出し、プロセス大量生成、採点妨害は禁止です。

ヒントは運営側の `./gameday.sh hint 問題番号 段階`。各問題に3段階あり、今回は無料です。
