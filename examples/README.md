# Standalone examples

These examples run outside the TenkaCloud problem catalog. They are not registered Portal problems and do not provide a platform runtime or scoring adapter.

- [Nightshift Bash Battle](nightshift-bash/README.md): investigate and repair a disposable Linux order-processing service using the organizer CLI. [日本語](nightshift-bash/README.ja.md).

Catalog-ready problems belong under `challenges/` or `battles/` and must satisfy the supported metadata, runtime, verifier, and participant-access contracts in [AGENTS.md](../AGENTS.md).
