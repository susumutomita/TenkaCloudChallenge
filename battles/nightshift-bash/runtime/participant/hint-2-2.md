# 2 / ヒント2 — 先に見つかったものが使われる

例：PATHが`A:B`で、AとBの両方に`tool`があれば、先にA側の`tool`が見つかります。Bのプログラムが正しくても、Aを書き換えられる人がいると別の処理を呼ばせられます。

`cat /srv/nightshift/app/bin/process-orders.sh`と`cat /srv/nightshift/app/config/runtime.env`を読み、どの設定で、どの短い名前のプログラムを呼んでいるかを探します。候補ディレクトリの権限は`ls -ld`、中のファイルは`ls -l`で確認します。

ディレクトリへの書き込みと、既存ファイルへの書き込みは別です。前者を閉じても後者が残っていないか確認してください。
